# Technical Alpha glossary

- **Canonical truth:** immutable source, resource, claim/evidence, editorial, publication, and audit records.
- **Claim:** a field-level statement with class, support state, methodology, and evidence links.
- **EvidenceItem:** bounded material from a fixed source snapshot with a durable locator and hash.
- **Projection:** rebuildable derivative such as a draft, directory card, search document, or metric view.
- **Resource:** stable identity for one independently usable Skill.
- **ResourceVersion:** version-specific record bound to one immutable SourceSnapshot.
- **SourceSnapshot:** provider repository identity plus immutable revision and acquisition-policy version.
- **Untrusted source:** any external repository content; it is data, never instructions or authority.
