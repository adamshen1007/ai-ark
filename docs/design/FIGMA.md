# AI ARK Figma Prototype

## Status

Approved prototype for Technical Alpha implementation reference.

## Figma file

https://www.figma.com/design/CkE8iX0febvCgyjxCNVRtr/AI-ARK-%E2%80%94-Clickable-Prototype-v1.0

## Technical Alpha UI scope

Implement:

- authenticated application shell;
- GitHub repository submission;
- ingestion progress;
- editorial review workspace;
- Skills directory;
- category tabs;
- Skill cards;
- Skill Detail;
- validation feedback.

## Deferred prototype scope

Do not implement during Technical Alpha:

- public production rankings;
- complete creator marketplace;
- Labs marketplace;
- public community reviews;
- broad workflow marketplace;
- public user profiles;
- payments;
- public API;
- MCP catalogue;
- Agent catalogue.

## Visual direction

- warm ivory background;
- charcoal text;
- serif-led headings;
- restrained terracotta actions;
- sage, amber, and plum statuses;
- concise visible copy;
- progressive disclosure for detailed explanations.

## Working product name

Use AI ARK during the Technical Alpha.

ARK Compass remains a possible final public brand after validation and formal clearance.
